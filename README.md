# 🧠 AI Study & Meeting Assistant

A Streamlit web application that uses DeepSeek AI to:
1. **Study Assistant**: Generate summaries and practice questions from any topic or notes
2. **Meeting Minutes Assistant**: Extract action points, decisions, and personal tasks from meeting minutes

## How It Works

### Study Assistant
- Enter a topic or paste your notes
- AI generates a 1-paragraph summary + 5 practice questions with answers
- Download results as a text file

### Meeting Minutes Assistant
- Paste meeting minutes or upload a text file
- AI extracts:
  - Summary
  - Key decisions
  - Action points (with responsibilities and deadlines)
  - **Your personal tasks** (highlighted)
  - Process/next steps
- Download results as a text file

## Technologies Used
- **Python** - Core programming language
- **Streamlit** - Web interface framework
- **DeepSeek API** - AI model for text generation
- **python-dotenv** - Environment variable management
